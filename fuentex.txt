ANÁLISIS DE RESPONSABILIDAD DE ARCHIVOS - Frontend AustralFinance

1. index.html
   - Estructura de la página: DOCTYPE, head (meta, enlaces a CSS/fonts, favicon), body
   - Contiene skip-link para accesibilidad
   - Mantiene el div raíz #app
   - Configura window.AUSTRAL_CONFIG con API_URL y USE_DEMO_DATA
   - Carga app.js como type="module"

2. css/styles.css
   - Sistema completo de estilos UI: variables CSS (colores, radios, sombras, espaciados)
   - Restos globales (box-sizing, scroll-behavior, configuración de fuentes)
   - Componentes de layout: header, nav, container, page, surface
   - Badges de estado, métricas, charts, tooltips
   - Badges de modo de datos (REAL/DEMO/UNAVAILABLE)
   - Layouts específicos mercado/oracle/infraestructura
   - Diseño responsive vía media queries (980px, 720px, 480px)
   - Preferencias de movimiento reducido

3. server.cjs
   - Servidor HTTP Node.js (puerto 4173, 127.0.0.1)
   - Routing SPA: redirige rutas conocidas (/ , /markets, /oracle, /infrastructure) a /index.html
   - Mapeo de tipos MIME para .html, .css, .js, .png, .jpg, .svg
   - Protección contra path traversal (verifica filePath startsWith root)
   - Manejo de errores 403 Forbidden y 404 Not Found

4. js/app.js
   - Punto de entrada y router de la aplicación
   - Crea app state via createAppState()
   - routeFromPath(): mapea URLs a rutas
   - isMarketRoute(): identifica rutas mercado (/ o /markets)
   - renderNavigation(): genera enlaces nav con estado activo
   - renderRoute(): despacha a renderMarket, renderOracle o renderInfrastructure
   - renderShell(): ensambla shell HTML completo (header, nav, wallet, sync-strip, main, footer, toast)
   - bindShellEvents(): vincula handlers click para navegación, wallet, menú, mejoras mercado
   - render(): renderiza shell en root y vincula eventos
   - navigate(): history.pushState y state.setRoute
   - Suscribe a cambios de estado via state.subscribe(render)

5. js/api.js
   - Cliente API para comunicación con backend
   - getApiBase(): lee API_URL de window.AUSTRAL_CONFIG
   - requestJson(): fetch con abort controller, timeout, cache no-store
   - normalizeOracle(): normaliza payload oracle (price, ema, lastPrint, bid, ask, spread, ccl, impliedCcl, crossCheck, status, source, marketOpen, freshness, circuitBreaker)
   - normalizeMarket(): normaliza payload market (markPrice, indexPrice, fundingRate, maxLeverage, marketStatus, hip3Status, pusherStatus, volume24h, openInterest, change24h, history, raw)
   - normalizeHealth(): normaliza payload health (status, version, raw)
   - loadSnapshot(): carga concurrente health, oracle, market recursos con mensajes fallback

6. js/state.js
   - Gestión de estado de la aplicación
   - createAppState(): crea estado inicial con route "/", loading:true, snapshot vacío
   - Objeto state con: route, loading, lastRefresh, snapshot (health/oracle/market), listeners Set
   - Métodos: get(), subscribe(listener), setRoute(route), refresh()
   - refresh(): carga datos demo si AUSTRAL_CONFIG.USE_DEMO_DATA=true, de lo contrario llama loadSnapshot()
   - notify(): notifica a todos los listeners cuando cambia el estado

7. js/utils.js
   - Funciones utilidad usadas en todo el código
   - isAvailable(): verifica que valor no sea undefined/null/""
   - valueOrDash(): retorna formatter(value) o "—" si no disponible
   - firstValue(): retorna primer valor disponible de source object dado listado de keys
   - formatPrice(): formatea número como $X.XXXX
   - formatPercent(): formatea porcentaje con signo +/−
   - formatNumber(): formateo general de número con Intl
   - formatBoolean(): formateo Yes/No
   - formatTimestamp(): formato HH:MM:SS
   - relativeTime(): "Xs ago", "Xm ago", "Xh ago"
   - normalizeStatus(): uppercasa y reemplaza -/s con _
   - readableStatus(): convierte _ a espacios
   - statusTone(): retorna "positive"/"warning"/"negative"/"neutral"/"active" según valor status
   - escapeHTML(): escaping de entidades HTML
   - statusBadge(): renderiza <span class="status-badge"> con tono codificado por color
   - modeBadge(): renderiza badge modo datos (REAL/DEMO/UNAVAILABLE)
   - safeErrorMessage(): extrae mensaje amigable de errores fetch (AbortError → "Request timed out")

8. js/components/common.js
   - Funciones de componentes UI reutilizables
   - icon(): retorna ruta SVG para íconos nombrados (arrow, arrowUp, chart, database, shield, pulse, info, warning, wallet, network, check, external)
   - pageHeader(): renderiza <header class="page-header"> con eyebrow, title, accent, description, meta
   - metricCard(): renderiza <article class="metric-card"> con label, value, detail opcional
   - emptyNotice(): renderiza div notice con icono y mensaje (soporta tonos error/warning/default)
   - sectionHeader(): renderiza <div class="surface__header"> con título, subtítulo, badge opcional
   - statusWithMode(): combina status badge con mode badge
   - priceWithLabel(): renderiza <div class="summary-metric"> con label y value

9. js/components/chart.js
   - Renderizado de chart de precio via SVG
   - normalizePoints(): normaliza puntos chart (maneja números u objetos con price/ema/timestamp)
   - linePath(): genera string path SVG (comandos M/L) para puntos
   - renderPriceChart(): renderiza SVG chart completo con grid, labels, línea precio, línea EMA, área llenada
   - Ancho por defecto: 920, altura: 350, padding: {top:22, right:58, bottom:34, left:12}
   - Retorna fallback "Historical data unavailable" si < 2 puntos

10. js/demo-data.js
    - Contiene fixture DEMO_SNAPSHOT
    - Fixture explícito para revisión visual, nunca presentado como datos live
    - Snapshot mock completo con modo: "simulated"
    - Contiene health, oracle y market data con estructura completa normalización
    - Usado por state.js refresh() cuando USE_DEMO_DATA=true

11. js/views/infrastructure.js
    - Renderizado página infraestructura/flujo de datos
    - infrastructureCard(): renderiza <article class="infra-card"> con título, tag, badge estado, lista items, footer
    - renderDiagram(): renderiza diagrama arquitectura con nodos (AUSTRAL.FI, ORACLE ENGINE, HIP-3, HYPERCORE, ASSETORACLE, HYPEREVM) y conectores
    - renderInfrastructure(): export principal - renderiza página infraestructura completa
    - Muestra flujo de datos: Data912 → Oracle Engine → HIP-3/HyperCore y AssetOracle/HyperEVM
    - Muestra estados componentes (Data source, Oracle Engine, HIP-3, HyperCore, HyperEVM)
    - Maneja modo demo vs status backend real

12. js/views/market.js
    - Renderizado página mercado/perpetuos
    - renderMarket(): export principal - renderiza página mercado completa
    - renderMarketHeader(): header con nombre instrumento (YPF-PERP), badge estado, cambio 24h, referencia oracle
    - renderChartPanel(): chart histórico con toolbar (períodos 1H/1D/1W) y renderPriceChart
    - renderMetrics(): panel métricas con precio index, mark price, volumen 24h, open interest, funding rate, max leverage
    - renderOracleSummary(): resumen estado oracle con badge modo, fresherness, source, grid métricas, enlace volver /oracle
    - enhanceMarket(): mejoras interactivas para botones trade y periodos
    - Maneja estados error e indicadores modo demo

13. js/views/oracle.js
    - Renderizado página oracle/motor precio
    - renderOracle(): export principal - renderiza página oracle completa
    - sourceCard(): renderiza <article class="source-card"> con icono, título, eyebrow, body, chips assets
    - pipelineStatus(): renderiza badge estado para un paso pipeline
    - renderPipeline(): renderiza pipeline oracle de 6 pasos (Data912 → Normalize → CCL Cross-check → Circuit Breaker → EMA → Published Price)
    - renderMetrics(): tabla métricas oracle (Last Print, EMA, Bid, Ask, Spread, CCL, Implied CCL, Market Open, Source, Freshness, Status)
    - renderCircuitBreaker(): circuit breaker visual con barra threshold, barra desviación actual, ticks release
    - renderEma(): tarjeta EMA con descripción
    - Muestra fuentes datos, assets, chips referencia, pipeline, grid métricas y circuit breaker

14. tests/smoke.mjs
    - Smoke test normalización API
    - Importa normalizeMarket y normalizeOracle de js/api.js
    - Prueba normalización oracle: price, ema, circuitBreaker.status, source
    - Prueba normalización market: markPrice, indexPrice, history.length, volume24h (esperado undefined)
    - Loguea "AustralFinance API normalization smoke test passed" en éxito

    - Documentación del proyecto

    - Explica organización en tres niveles: mercado YPF-PERP, Oracle, infraestructura

    - Configuración backend via window.AUSTRAL_CONFIG en index.html
    - Modo DEMO_DATA: USE_DEMO_DATA true usa fixture js/demo-data.js
    - Endpoints API: GET /health, GET /oracle/price/YPF, GET /market/YPF-PERP
    - Diagrama visión general estructura
    - Verificación: node tests/smoke.mjs, node --check para validación módulos
    - Documenta datos no implementados: no backend, contratos, ABI, endpoints chain
    - Fixture demo muestra Volume/Open Interest/estados blockchain visibles solo en contexto DEMO DATA
